# Замер цитируемости mi-code.pl в ИИ-движках

**Дата:** 2026-08-11
**Статус:** согласовано, готово к планированию

## Задача

Сайт уже подготовлен под цитирование ИИ: `public/llms.txt`, `robots.txt` с явным
Allow для GPTBot / ClaudeBot / PerplexityBot / Google-Extended / CCBot,
трёхъязычный пререндер, JSON-LD, sitemap. Чего нет — измерения: мы не знаем,
цитируют ли нас на самом деле и растёт ли это со временем.

**Цель:** повторяемый ряд данных о цитируемости, который видно в git и который
не требует платных сервисов.

**Ограничение:** только бесплатные источники. Платные трекеры (Profound, Peec,
Semrush AI Toolkit) делают ровно это, но стоят $100–500/мес.

## Что вообще можно померить бесплатно

| Слой | Источник | Автоматизация | Что показывает |
|---|---|---|---|
| Активный | Gemini API, free tier, Google Search grounding | еженедельно по cron | реальный список процитированных URL |
| Активный | ChatGPT / Perplexity через залогиненный Chrome | вручную, раз в месяц | правду по движкам, где нет бесплатного API |
| Пассивный | Cloudflare AI Crawlers + рефералы GA4 | вручную, раз в месяц | факт визитов ботов и людей из ИИ |

У Perplexity и OpenAI веб-поиск в API платный, поэтому по расписанию честно
работает только Gemini. Остальные два слоя пишут в тот же формат, чтобы отчёт
был сквозной.

## Метрика

Для каждого промпта — один из трёх статусов:

| статус | как определяется |
|---|---|
| `cited` | `mi-code.pl` есть среди источников ответа |
| `mentioned` | бренд встречается в тексте ответа, ссылки на нас нет |
| `absent` | ни того, ни другого |

Метрика прогона — доля `cited`, отдельно по языкам и по типу запроса.

Ответы движков недетерминированы: один и тот же промпт даёт разные источники.
Поэтому каждый промпт гоняется **дважды**, итоговый статус — лучший из двух
(`cited` > `mentioned` > `absent`). Это не убирает дрожание полностью, но
недельный ряд в git делает его видимым.

## Компоненты

### `docs/seo/ai-visibility/prompts.json`

Единственный файл, который правят руками — при добавлении продукта или статьи.

```json
{
  "domain": "mi-code.pl",
  "brandTerms": ["MiCode", "mi-code.pl", "eKsiegowyAi", "eMarketingAI",
                 "ngx-open-web-ui-chat", "Legalka"],
  "prompts": [
    {
      "id": "pl-ksiegowosc-wfirma",
      "lang": "pl",
      "kind": "category",
      "text": "Czy istnieje asystent AI, który łączy się z wFirma i odpowiada na pytania o VAT i PIT?",
      "target": "/products/accounting-ai/"
    }
  ]
}
```

`kind` — `category` (клиент, который нас не знает) или `brand` (контрольный).
`target` — страница, которую мы надеемся увидеть в источниках; на классификацию
не влияет, нужна для отчёта.

**Стартовый набор — 27 промптов.**

Категорийные, PL (10): фирма-разработчик с AI в Гданьске; ассистент к wFirma по
VAT/PIT; месячная стоимость LLM-агента; RAG-бот, который говорит «не знаю»;
как попасть в цитаты ChatGPT; бот для легализации пребывания в Польше;
обязанности по AI Act в 2026; Text2SQL и RAG для предприятий; интеграция агента
с ERP и цепочкой поставок; польская SaaS-платформа генерации контента.

Категорийные, EN (8): AI-чат в Angular одной установкой npm; Angular-библиотека
к Open WebUI; из чего складывается стоимость LLM-агента; самообучающиеся команды
агентов; LangGraph-агент с 80+ инструментами; что такое GEO; платформы генерации
тест-кейсов из кодовой базы; software house в Польше под enterprise AI.

Категорийные, RU (5): бот для легализации в Польше; стоимость AI-агента в месяц;
RAG без галлюцинаций; как попасть в ответы ChatGPT и Perplexity; AI-помощник по
польским налогам.

Брендовые контрольные (4): чем занимается MiCode Sp. z o.o. (pl, en); что такое
eKsiegowyAi; что такое пакет ngx-open-web-ui-chat.

Брендовые — канарейка. Если нас нет даже по прямому запросу про компанию,
сломалась индексация, а не маркетинг, и чинить надо другое.

### `scripts/ai-visibility.mjs`

Без зависимостей, на нативном `fetch` — как остальные `.mjs` в `scripts/`.

Ход работы:

1. Читает `prompts.json`.
2. На каждый промпт — 2 вызова `generateContent` с включённым инструментом
   `google_search`. Модель и число повторов берутся из env
   (`AI_VIS_MODEL`, `AI_VIS_REPEATS`) со значениями по умолчанию в коде.
3. Из `groundingMetadata.groundingChunks[]` достаёт источники и резолвит хост.
4. Классифицирует, агрегирует, пишет `docs/seo/ai-visibility/runs/YYYY-MM-DD.json`.
5. Пересобирает `docs/seo/ai-visibility/REPORT.md` с текущими числами и дельтой
   к прошлому прогону.
6. В stdout — число сделанных вызовов, чтобы расход по лимиту был виден в логе.

**Резолв источников — ключевая деталь.** Gemini отдаёт не прямые ссылки, а
редиректы вида `vertexaisearch.cloud.google.com/grounding-api-redirect/...`.
Если сравнивать домен с этим URL, мы не увидим себя никогда. Порядок: сначала
поле `web.domain`, если его нет — HEAD-запрос по редиректу и разбор финального
хоста. Не разрешившийся источник попадает в отчёт как `unknown` и не роняет
прогон.

Формат `runs/YYYY-MM-DD.json`:

```json
{
  "date": "2026-08-11",
  "source": "gemini",
  "model": "<модель, которой сделан прогон>",
  "calls": 54,
  "results": [
    {
      "id": "pl-ksiegowosc-wfirma", "lang": "pl", "kind": "category",
      "status": "cited",
      "attempts": [
        { "status": "cited", "citedUrls": ["https://mi-code.pl/products/accounting-ai/"],
          "sourceDomains": ["mi-code.pl", "wfirma.pl"] },
        { "status": "absent", "citedUrls": [], "sourceDomains": ["poradnikprzedsiebiorcy.pl"] }
      ]
    }
  ],
  "summary": {
    "byLang": { "pl": { "cited": 2, "mentioned": 1, "absent": 7 } },
    "byKind": { "category": { "cited": 1, "mentioned": 3, "absent": 19 },
                "brand":    { "cited": 3, "mentioned": 1, "absent": 0 } },
    "citedShare": 0.148
  }
}
```

### `docs/seo/ai-visibility/manual/YYYY-MM.json`

Ручной слой, раз в месяц, в схеме, совместимой с автоматической:

```json
{
  "month": "2026-08",
  "source": "manual",
  "crawlers": { "GPTBot": 0, "ChatGPT-User": 0, "OAI-SearchBot": 0,
                "PerplexityBot": 0, "ClaudeBot": 0, "Google-Extended": 0, "CCBot": 0 },
  "referrals": { "chatgpt.com": 0, "perplexity.ai": 0, "gemini.google.com": 0 },
  "engines": [
    { "engine": "chatgpt", "id": "pl-ksiegowosc-wfirma", "status": "absent", "note": "" }
  ]
}
```

`crawlers` и `referrals` переносятся из дашбордов Cloudflare и GA4 руками.
Разделение важное: `GPTBot`, `ClaudeBot`, `CCBot`, `Google-Extended` — это
обучение и индексация, а `ChatGPT-User`, `OAI-SearchBot`, `PerplexityBot`
приходят в момент ответа живому пользователю, то есть это и есть след
фактического цитирования.

`engines` заполняет Claude, прогоняя те же промпты в залогиненном Chrome.

### `.github/workflows/ai-visibility.yml`

По образцу `site-health.yml`: cron раз в неделю плюс `workflow_dispatch`,
Telegram-алерт через уже существующие секреты `TELEGRAM_BOT_TOKEN` и
`TELEGRAM_OPS_CHAT_ID`, новый секрет `GEMINI_API_KEY`.

- `permissions: contents: write` — воркфлоу коммитит результат в `development`.
- **Коммит обязан содержать `[skip ci]` в сообщении.** `deploy.yml` реагирует на
  любой push в `development` без фильтра путей, поэтому без этого еженедельный
  коммит бота запускал бы полный ребилд, перевыкачку статистики GitHub/npm,
  перерисовку OG-картинок и деплой — на изменение файла в `docs/`.
- Сообщение в Telegram уходит **только если поменялся набор `cited`-промптов**:
  списком «появилось» и «пропало». Первый прогон (нет предыдущего) — просто
  базовая линия без сообщения.
- Отсутствие секретов не маскирует падение: warning в лог, job остаётся красным,
  письмо от GitHub уходит — та же логика, что в `site-health.yml`.

Расход: 27 промптов × 2 повтора = 54 вызова в неделю, с запасом внутри
бесплатного лимита.

## Обработка ошибок

| Ситуация | Поведение |
|---|---|
| 5xx или 429 на вызове | 1 ретрай с задержкой |
| Ретрай не помог | прогон прерывается, exit 1, файл не пишется и не коммитится |
| Редирект источника не резолвится | источник помечается `unknown`, прогон продолжается |
| Ответ без `groundingMetadata` | статус считается по тексту ответа: `mentioned` или `absent` |
| Нет предыдущего прогона | дельта не считается, Telegram молчит |

Частичный прогон не сохраняется намеренно: полупустой замер испортил бы ряд и
выглядел бы как обвал цитируемости.

## Тесты

`scripts/ai-visibility.test.mjs` рядом со скриптом — по образцу
`scripts/generate-og-images.test.mjs`. Vitest подхватывает его дефолтным
`include` (в `vite.config.ts` свой `include` не задан).

Сеть в тестах замокана полностью. Покрываем чистые функции:

- `classify()` — три статуса, включая случай «домен в источниках, но бренда нет
  в тексте» и обратный;
- `resolveHost()` — прямой URL, редирект Gemini, поле `web.domain`,
  неразрешимый источник;
- `summarize()` — агрегация по языку и типу, лучший из двух повторов;
- `diffRuns()` — появилось / пропало / без изменений / нет предыдущего прогона;
- `renderReport()` — отчёт собирается и на первом прогоне тоже.

## Что это не меряет

Записать прямым текстом в `REPORT.md`, чтобы через полгода никто не спутал
индикатор с полной картиной:

- Gemini — не ChatGPT. Ряд по одному движку показывает тренд индексируемости и
  цитируемости, а не долю во всех ИИ-ответах.
- Grounding в API и веб-интерфейс движка ранжируют по-разному.
- GA4-рефералы у нас включаются только после согласия на cookie, поэтому это
  всегда нижняя оценка.
- Отдельный прогон ничего не доказывает — значение имеет только ряд.

Поэтому ручной браузерный слой раз в месяц обязателен: без него метрика начнёт
врать сама себе.

## Риски

| Риск | Смягчение |
|---|---|
| Google меняет бесплатный лимит или имя модели | модель и число повторов в env, падение видно в Telegram |
| Cloudflare включит челлендж для AI-ботов | ручной слой это покажет: краулеры уйдут в ноль |
| Первые месяцы по категорийным запросам — ровный ноль | брендовые контрольные отделяют «нас не знают» от «нас не видно» |
| Промпты устаревают вслед за контентом | `prompts.json` обновляется вместе с новым продуктом или статьёй |

## Предусловие

Бесплатный ключ на `aistudio.google.com` и секрет `GEMINI_API_KEY` в
репозитории. Без него автоматический слой не поедет; код и тесты пишутся и
проверяются независимо.
